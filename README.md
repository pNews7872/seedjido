# 시드 지도 (seedjido.com)

마인크래프트 자바 에디션 시드 지도·시드 찾기 사이트예요.

- `public/` 안의 파일이 그대로 사이트가 돼요 (index.html, style.css, app.js, seed.wasm).
- `main` 브랜치에 올리면 Cloudflare가 자동으로 배포해요.

시드 지도는 Mojang Studios·Microsoft와 관계없는 비공식 팬 도구예요.
지형·구조물 계산은 [Cubiomes](https://github.com/Cubitect/cubiomes)와 [xpple/cubiomes](https://github.com/xpple/cubiomes)(둘 다 MIT 라이선스)를 사용해요.
