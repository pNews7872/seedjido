시드 지도지도 열기

지도 사용법

시드 하나를 열어서 바이옴, 구조물, 좌표를 둘러보는 방법이에요.

1. 시드 열기

지도 보기 탭의 시드 칸에 숫자나 글자 시드를 넣으면 바로 계산을 시작해요. 글자 시드는 게임과 같은 방식으로 숫자로 바꿔서 계산해요. 무작위 버튼을 누르면 아무 시드나 열려요. 처음 들어오면 매번 무작위 시드가 열려요.

게임 안에서 /seed 명령어로 지금 월드의 시드를 확인할 수 있어요.

2. 지도 움직이기

  • 이동: 마우스로 끌거나, 휴대폰에서는 한 손가락으로 밀어요.
  • 확대·축소: 마우스 휠, 두 손가락 벌리기, 또는 오른쪽 위 + − 버튼을 써요.
  • ★ 버튼: 스폰 지점으로 돌아가요. ⛶ 버튼은 지도를 전체 화면으로 키워요.
  • 지도 위 격자는 512칸 간격이에요. 월드 파일(region) 하나의 크기와 같아요. 위쪽에 X 좌표, 왼쪽에 Z 좌표가 적혀 있고, 0, 0 지점은 흰 점으로 표시돼요.

3. 차원과 보기 방식

차원에서 오버월드, 네더, 엔드를 고를 수 있어요. 오버월드에서는 보기를 지도(평면), 지형(입체감 있는 음영), 3D 중에서 고를 수 있고, 바이옴 색은 기본 색과 게임 지도 색 중에서 고를 수 있어요.

4. 구조물 고르기

표시할 구조물에서 보고 싶은 것만 눌러 켜고 끌 수 있어요. 고른 상태는 브라우저에 저장돼서 다음에 와도 그대로예요. 아이콘이 너무 크거나 작으면 아이콘 크기 막대로 조절하세요.

구조물 아이콘을 누르면 좌표, 높이, 종류 같은 정보가 나와요. 예를 들어 마을은 평원·사막·사바나·타이가·설원 중 어떤 마을인지, 이글루는 지하실이 있는지, 엔드 도시는 배가 있는지와 배의 높이까지 알려 줘요.

5. 좌표 이동과 즐겨찾기

  • 지도 아래 즐겨찾기·이동 칸에 X, Z를 넣고 이동을 누르면 그 위치로 가요.
  • 지도의 빈 곳이나 구조물을 누르면 나오는 창에서 이름을 적고 ★ 저장을 누르면 즐겨찾기에 들어가요. 집, 농장, 차원문 같은 곳을 저장해 두세요.
  • 즐겨찾기는 시드마다 따로, 이 브라우저에 저장돼요.

6. 네더 차원문 연결 좌표

오버월드에서 어느 지점을 누르면 창에 "네더에서는 X, Z"가 함께 나와요. 오버월드 좌표를 8로 나눈 값이에요. 반대로 네더에서 누르면 오버월드 좌표(×8)가 나와요. 오버월드에 저장한 즐겨찾기는 네더 지도에도 흐리게 표시돼서, 네더 쪽 차원문을 어디에 지으면 되는지 바로 보여요.

7. 링크로 공유하기

지도 아래 지금 화면 링크 복사를 누르면 시드, 차원, 위치, 확대 상태가 담긴 링크가 복사돼요. 친구에게 보내면 같은 화면이 그대로 열려요.
